# Python dependencies for reproducing the inter-row shading evidence.

#   python -m venv .venv && .venv/Scripts/activate   (Windows)

#

#             used by pvlib_crosscheck.py to check our derivation against someone else's.
# numpy       vectorises the sweep in pvlib_crosscheck.py.
# matplotlib  renders the evidence figure (evidence_figure.py).
